The ``1-my_list`` module
=========================

Using MyList
------------

Import MyList from the module::

    >>> MyList = __import__('1-my_list').MyList

Create a MyList and append integers::

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Print it sorted::

    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The original list is unchanged::

    >>> print(my_list)
    [1, 4, 2, 3, 5]

Print sorted with negative numbers::

    >>> my_list_2 = MyList()
    >>> my_list_2.append(3)
    >>> my_list_2.append(-1)
    >>> my_list_2.append(0)
    >>> my_list_2.append(-5)
    >>> my_list_2.print_sorted()
    [-5, -1, 0, 3]

Print sorted with an empty list::

    >>> empty_list = MyList()
    >>> empty_list.print_sorted()
    []
